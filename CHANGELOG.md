# Changelog

## 0.2.1 (November 2026)

The first public release.

- **Connect in one click.** Connect buttons in the app add Windfall3D to Claude Desktop, the
  ChatGPT desktop app or Claude Code, backing up their settings first. Remove undoes it.
- **Longer builds.** A build can now run for up to 5 minutes, so large assemblies finish.
- **Safer updates.** The installer closes a running Windfall3D before updating it.
- **Sturdier window.** If the 3D view cannot start, the panel, Help and Connect still work, and
  the window retries the view.
- Help covers connecting each assistant, exporting files and troubleshooting.

## 0.2.0

- The Windfall3D app: a window that shows each model live as your assistant builds it, with its
  verdict and every check.
- The app and your assistant share one Windfall3D, so whatever your assistant builds appears in the
  window.
- Works with the ChatGPT desktop app in Work mode.
- Built-in Help.
