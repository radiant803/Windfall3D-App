# Security

If you find a security problem in Windfall3D, please report it privately rather than in a public
issue: use **[Report a vulnerability](https://github.com/radiant803/Windfall3D-App/security/advisories/new)**
on this repository's Security tab.

Please include the Windfall3D version, your operating system, and the steps to see the problem.
We will reply there.

Only the latest version is supported with security fixes.
