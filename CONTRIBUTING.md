# Reporting issues

Thank you for helping improve Windfall3D. Windfall3D is closed source, so this repository takes
bug reports, feature requests and requests for help, not code changes.

1. Read the [guide](README.md) and the Help in the app; most setup questions are answered there.
2. Search the [existing issues](https://github.com/radiant803/Windfall3D-App/issues?q=is%3Aissue)
   for your problem.
3. Open a new issue with one of the [forms](https://github.com/radiant803/Windfall3D-App/issues/new/choose).

## How issues are screened

Every new or edited issue is checked automatically. It must:

- be made with one of the forms, with a title that says what it is about;
- give a released Windfall3D version, and for bugs and help, the latest one;
- describe the problem in at least a sentence or two, with steps to reproduce it for bugs;
- have every box ticked;
- not repeat an open issue, and contain no more than 5 links.

An issue that misses any of these is closed with a comment listing what to add. Edit the issue
to add it, and it reopens by itself. An issue that passes is labelled **pending review** until a
maintainer labels it **approved** or **rejected**.

Please leave personal details out of reports, such as file paths that contain your name.
